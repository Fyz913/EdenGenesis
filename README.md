# 🌍 Eden Genesis · 伊甸创世录

**第一人称视角的文明演化模拟器** —— 一个从村庄到国家、从狩猎采集到星际文明、完全靠自己生长的世界。

> 这不是「NPC + 地图」游戏，而是一层一层叠加起来的文明模拟：
> **居民 → 家庭 → 职业 → 经济 → 社会 → 政治 → 外交 → 战争 → 城市 → 国家 → 科技 → 文化**
>
> 玩家不做「上帝」，只做「见证者」。几百年的世界变化，是文明自己一步步走出来的。

                ↓

                ↓

                ↓
              政府
        ┌───────┴───────┐
        ↓               ↓
      外交            军队
        ↓               ↓
   贸易 / 联盟        战争
        ↓               ↓
        └───────┬───────┘
                ↓
             文明历史
                ↓
             下一代居民

战争不是「另一个独立小游戏」——战争影响经济、政治、外交和居民记忆；战争结束后有和平条约、贸易恢复和战后重建。

## 如何运行

1. 安装 [Godot 4.7](https://godotengine.org/)（4.x 兼容）
2. 用 Godot 打开 `project.godot`（或导入本目录）
3. 按 **F5** 运行，主场景 `scenes/world.tscn`，窗口 1280×720
4. 无需联网、无需外部依赖即可完整运行

## 操作方式

| 按键 | 功能 |
|---|---|
| **W A S D** | 移动（W 前 / S 后 / A 左 / D 右） |
| **E** | 交互（与居民/建筑交互） |

## 性能架构（Alpha 0.19.x 核心重构）

世界可以很大，但玩家眼前只运行真正需要运行的东西：

- **模拟时钟分层**：帧→秒→分钟→小时→天→周→月→年，各系统按自己的节奏运行，绝不每帧全量计算
- **NPC LOD 三级**：LOD0 玩家附近真实 NPC（动画/碰撞/AI）→ LOD1 中距离简化 NPC → LOD2 远距离纯数据人口（百万人口也只生成几十个 3D 实体）
- **空间网格（SpatialGrid）**：NPC 只查询附近 Cell，禁止全体两两互查
- **对象池 + 分帧加载**：减少 instantiate/queue_free，每帧最多加载 20 个视觉对象
- **AI Tick Budget**：每帧只处理有限数量的完整 AI
- **History/Memory 分层**：普通事件压缩归档，重大事件永久保留，防止无限增长
- **统一 WorldTime**：所有系统只读 TimeManager，信号防重复连接
- **EntityRegistry + SaveValidator**：防止重复 ID、断裂引用，存档分文件 + 版本号迁移

压力测试目标：**1000 真实 NPC + 10000 模拟 NPC + 100000 数据人口** 长时间运行 FPS 与内存稳定。

## 数据与存档

- `data/`：世界初始种子（文明、NPC、家庭、科技）
- 存档按模块分文件：`world / time / humans / families / cities / countries / economy / wars / technology / regions / infrastructure / history ...`
- 带 `save_version` 版本号，旧存档可平滑迁移
- 手动保存 + 重大事件自动保存（国家成立、战争结束、城市建立等）

## 设计原则

- **增量开发**：每个 Alpha 版本在旧系统上扩展，禁止重建第二套 Manager
- **战争不能凭空产生军队**：军队受人口、财政、装备、粮食、后勤限制
- **数字必须是真实的**：UI 上的每个数字都来自真实模拟系统，不做「假繁荣 +50」
- **模拟与表现分离**：Simulation 决定世界发生了什么，Rendering 决定玩家看见什么
